# Image to PDF Converter

A powerful and user-friendly tool to convert images to PDF format quickly and easily.

## 🌟 Features

- **Multiple Image Format Support** - Convert JPG, PNG, GIF, BMP, TIFF, and WebP images to PDF
- **Batch Processing** - Convert multiple images at once
- **Drag & Drop Interface** - Simple drag and drop functionality for easy file upload
- **No Installation Required** - Works directly in your browser
- **Privacy Focused** - All processing happens locally on your device
- **Free to Use** - Completely free, no hidden charges or limitations
- **Fast Processing** - Quick conversion with optimized performance
- **High Quality Output** - Maintains image quality during conversion
- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices

## 🚀 Getting Started

### Usage
1. Open the application in your web browser
2. Upload one or more images by clicking the upload button or dragging them into the designated area
3. Arrange the images in your desired order (if multiple images)
4. Click the "Convert to PDF" button
5. Your PDF file will be automatically downloaded

### Supported Image Formats
- JPEG (.jpg, .jpeg)
- PNG (.png)
- GIF (.gif)
- BMP (.bmp)
- TIFF (.tiff, .tif)
- WebP (.webp)

## 📋 How It Works

The application uses client-side JavaScript libraries to:
1. Read images from your device
2. Process and optimize the images
3. Generate a PDF file containing all images
4. Download the PDF directly to your device

## 💡 Tips for Best Results

- Use high-quality images for better PDF output
- Keep image file sizes reasonable (under 10MB each)
- For better organization, arrange images before conversion
- Supported color formats include RGB, CMYK, and grayscale

## 🐛 Troubleshooting

### Issue: Image not uploading
- Ensure the file is in a supported format
- Check that your browser is up to date
- Try a different image file

### Issue: PDF file is too large
- Compress your images before uploading
- Reduce image resolution if necessary
- Process fewer images at once

### Issue: Poor image quality in PDF
- Use higher resolution source images
- Avoid heavily compressed image formats
- Ensure images meet minimum dimension requirements
